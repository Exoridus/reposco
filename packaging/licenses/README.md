# Qt license text provenance

The Qt license texts are copied verbatim from qt/qtbase tag v6.12.0, source commit `025bdad181de241e81bf853c8a2d7bf3d19261a9`, directory LICENSES. The commercial license reference is excluded. These generic license texts do not imply that every listed third-party component is deployed.

Before publishing, inspect the exact deployed Qt module SBOMs and supply their copyright notices and complete corresponding source. Qt SDKs may omit a top-level LICENSES directory, so packaging uses these tracked texts rather than silently omitting license materials. Original legal whitespace is preserved through a scoped .gitattributes exception.
