# Architecture

src/app owns composition and HistoryWorker. UI owns DesktopSession, HistoryController, HistoryModel, QML, QWindowKit and tray actions. Closing the palette hides it. Tray Quit disables capture, drains/closes storage and stops the native listener before ending the Qt event loop.

reposco_core is plain C++20 without Qt or native dependencies: bounded text admission, exclusion screening and UTF-16 validation. ClipboardTextSource exposes semantic marker checks and one bounded payload read so tests can prove exclusion before access. reposco_text adds portable QtCore Unicode normalization and versioned SHA-256 identity. Smart comparison uses LF, NFC and edge trimming while original UTF-8 remains unchanged. The SDK-free Linux lane tests reposco_core; Qt normalization is currently tested on Windows.

reposco_storage owns synchronous SQLCipher connections, schema and prepared statements. HistoryWorker owns its only connection on a QThread, along with a per-profile writer lock, preferences and periodic retention. Key/file/database operations never run on the GUI thread in normal operation. HistoryStore updates payload, recency and eviction transactionally; unknown schemas and ambiguous identities fail closed. UI sees at most 100 summaries of 200 characters and a selected plain-text fallback bounded to 8192 characters with worker-generated offline previews, not database handles. Full original representations is retrieved only for explicit replay, with at most one storage request outstanding; canceled replies are discarded. Literal search is bounded to 256 characters. Search and preview each allow one outstanding worker request, coalesce newer requests and reject stale replies after clear or shutdown.

reposco_platform_windows owns user-scope DPAPI, BCrypt random keys, thread-bound hotkeys and NativeClipboardMonitor. ClipboardMonitor is the presentation/application seam used by the Windows implementation and synthetic test adapter. A dedicated STA owns a native message-only listener and all clipboard reads. Three bounded lock attempts use message-loop timers. Only one captured payload can await storage acknowledgement; further changes coalesce to the latest sequence. Pause generations invalidate delayed/queued results. Privacy changes use a bounded asynchronous worker barrier: capture stays paused and controls report pending until earlier operations finish and policy preferences are saved. A final admission predicate rolls back obsolete capture transactions before commit. The GUI never waits on storage locks. Delayed rendering can still delay capture and orderly shutdown; the GUI remains responsive. A bounded, cancelable restore mailbox reuses that STA and publishes monitor/local-history/cloud exclusion markers before supported original representations. DesktopSession captures the previous external HWND/process/thread identity on open. Paste requires an active foreground palette, eligible non-elevated target, unchanged clipboard sequence and released shortcut keys; it transfers focus and sends one balanced Ctrl+V request. No keyboard hooks or focus-lock bypasses are used. Original Unicode text, registered CF_HTML/RTF/PNG and bounded CF_DIB/CF_DIBV5 representations share one restore mailbox; plain-text replay deliberately strips other formats.

reposco_content uses QtGui for bounded image decoding and offline QTextDocument import. It separates original representations from searchable text, typed identity and preview. OfflineDocument returns empty resources without delegating to filesystem/network loaders. Markup is never supplied directly to interactive QML rendering. Storage schema v2 adds a versioned bounded representation packet and content kind transactionally; v1 IDs, text identities and recency survive migration. Unknown schema still locks without replacing files.

Dependencies flow down from app/UI to platform/core. Storage links pinned SQLCipher and source-built OpenSSL. QWindowKit private Qt ABI dependencies stay in its integration and UI adapter. Widgets is used for QApplication/QSystemTrayIcon; QWindowKit Widgets is disabled.
