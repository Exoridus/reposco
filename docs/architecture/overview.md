# Architecture

src/app owns composition and HistoryWorker. UI owns DesktopSession, HistoryController, HistoryModel, QML, QWindowKit and tray actions. Closing the palette hides it. Tray Quit disables capture, drains/closes storage and stops the native listener before ending the Qt event loop.

reposco_core is plain C++20 without Qt or native dependencies: bounded text admission, exclusion screening and UTF-16 validation. ClipboardTextSource exposes semantic marker checks and one bounded payload read so tests can prove exclusion before access. reposco_text adds portable QtCore Unicode normalization and versioned SHA-256 identity. Smart comparison uses LF, NFC and edge trimming while original UTF-8 remains unchanged. The SDK-free Linux lane tests reposco_core; Qt normalization is currently tested on Windows.

reposco_storage owns synchronous SQLCipher connections, schema and prepared statements. HistoryWorker owns its only connection on a QThread, along with a per-profile writer lock, preferences and periodic retention. Key/file/database operations never run on the GUI thread in normal operation. HistoryStore updates payload, recency and eviction transactionally; unknown schemas and ambiguous identities fail closed. UI sees at most 100 summaries of 200 characters and a selected original-text preview bounded to 8192 characters, not database handles or full payloads. Literal search is bounded to 256 characters. Search and preview each allow one outstanding worker request, coalesce newer requests and reject stale replies after clear or shutdown.

reposco_platform_windows owns user-scope DPAPI, BCrypt random keys, thread-bound hotkeys and NativeClipboardMonitor. ClipboardMonitor is the presentation/application seam used by the Windows implementation and synthetic test adapter. A dedicated STA owns a native message-only listener and all clipboard reads. Three bounded lock attempts use message-loop timers. Only one captured payload can await storage acknowledgement; further changes coalesce to the latest sequence. Pause generations invalidate delayed/queued results. Delayed rendering can still delay capture and orderly shutdown; the GUI remains responsive. No writer/paste backend exists yet.

Dependencies flow down from app/UI to platform/core. Storage links pinned SQLCipher and source-built OpenSSL. QWindowKit private Qt ABI dependencies stay in its integration and UI adapter. Widgets is used for QApplication/QSystemTrayIcon; QWindowKit Widgets is disabled.
