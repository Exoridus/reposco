# Security policy

Reposco is pre-release. No published version or third-party audit exists. Security fixes apply to the development tree.

Do not disclose sensitive data, keys or vulnerabilities in public issues. A project-specific private reporting channel has not yet been established. Before public release the maintainer must enable GitHub private vulnerability reporting or publish a verified contact here. Another project's reporting address is not reused. If private reporting becomes available, use the repository Security tab.

Reports should contain the affected revision, synthetic reproduction and impact without personal data. No response-time guarantee is offered. [The threat model](docs/security/threat-model.md) defines current gaps.
