# Contributing

Read [AGENTS.md](AGENTS.md) and the [development guide](docs/development/build-and-test.md). Work from main on a scoped branch. Preserve boundaries and add meaningful tests. Run targeted tests while editing and the integrated full gate before review.

Formatting and analysis are explicit commands. No Git hooks are required or installed. Checkpoint commits are encouraged; separate PRs for every task are unnecessary. Describe changed behavior, actual validation and limitations in reviews.

Never attach real clipboard contents, history files, keys or unsanitized crash dumps. Follow [SECURITY.md](SECURITY.md). Contributions use GPL-3.0-or-later.
